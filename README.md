# Desafio 1 | Sistema de Gerenciamento de Biblioteca

Início do desenvolvimento: 22/0

## Funcionalidades

1. Cadastrar livros;
2. Cadastrar usuários;
3. Realizar empréstimos de um livro para um usuário;
4. Registrar devoluções de um livro por um usuário;
5. Buscar livros por autor, categoria e título;
6. Buscar todos os livros, empréstimos ou usuários.
