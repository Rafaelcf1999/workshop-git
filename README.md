# Sistema de Gerenciamento de Biblioteca

Backend simples de gerenciamento de biblioteca, desenvolvido em
TypeScript, aplicando Repository Pattern e Strategy Pattern. Desafio do Fellowship Bootcamp AWS JS + TS 

## Funcionalidades
- Cadastro de livros e usuários
- Empréstimo e devolução de livros
- Busca de livros por autor ou categoria (extensível via Strategy Pattern)

## Tecnologias
- Node.js (24.10+) com suporte nativo a TypeScript
  (`--experimental-transform-types`, sem etapa de compilação)

## Como rodar
\`\`\`bash
npm install
npm start
\`\`\`
