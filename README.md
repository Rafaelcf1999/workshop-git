# Sistema de Gerenciamento de Biblioteca

Sistema de gerenciamento de biblioteca desenvolvido em **TypeScript**.

Estrutura do Projeto

```text
src/
├── entities/           # Entidades (Book, User, Loan)
├── repositories/       # Repositórios em memória e suas interfaces
│   └── interfaces/
├── services/           # Regra de negócio (LibraryService)
├── strategies/         # Padrão Strategy para buscas
└── index.ts            # Ponto de entrada e demonstração do sistema
```
