# Sistema de Gerenciamento de Biblioteca - Desafio

Projeto desenvolvido em TypeScript para gerenciamento de uma biblioteca, com cadastro de livros e usuários, controle de empréstimos e busca de livros por diferentes critérios.

## Autora

Giovana Sena de Carvalho

## Funcionalidades

- Cadastrar livros
- Cadastrar usuários
- Realizar empréstimos de livros
- Registrar devoluções de livros
- Buscar livros por autor
- Buscar livros por categoria
