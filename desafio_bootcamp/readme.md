# Desafio: Sistema de Gerenciamento de Biblioteca

Projeto é a implementação do backend de um sistema de biblioteca, desenvolvido como desafio técnico do Bootcamp.

## Tecnologias e Requisitos
- **Node.js**: v24.10+
- **TypeScript**: Adicionar tipagem estática e sem necessidade de compilação


## Como Executar

1. Clone o repositório e acesse a branch `kaique-caitano-desafio`.
2. Instale as dependências:
   ```bash
   npm install
   npm start
